PROCESS MANAGER PROJECT

Description:
A Python-based process monitoring application that displays running
processes, CPU usage, memory usage, I/O activity, and process
classification as CPU-bound, I/O-bound, or Balanced/Other.

Requirements:
- Windows
- Python 3 installed
- Internet connection for installing Python packages on first run

How to Run:
1. Extract the project ZIP.
2. Open the extracted folder.
3. Double-click Run_Process_Manager.bat.
4. Wait for dependencies to install and the dashboard to open.
Run main.py for the output to open in new window 

Features:
- Process monitoring
- System/User process identification
- CPU, memory, and I/O statistics
- CPU-bound and I/O-bound classification
- Search and process-type filtering
- CPU and memory charts
- SQLite process history logging
